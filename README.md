# Frisson Writing website

Static site for Frisson Writing LLC, served by GitHub Pages from the `main` branch.

- Pages: `index.html`, `services.html`, `work.html`, `approach.html`, `founder.html`, `contact.html`
- Styles and fonts: `assets/`
- Logo files: `assets/logo.svg`, `assets/logo-light.svg`, `assets/favicon.svg`
- Text and the project list live in `tools/build.py`. Run `python3 tools/build.py` to regenerate the pages.
- Report covers go in `assets/covers/<slug>.jpg`, and the founder photo in `assets/founder.jpg`.
